# v0.2.0

2026-10-23 · [Download](https://github.com/Abulkosim/wick/releases/tag/v0.2.0)

- Wick now runs on Windows 10 and 11 (x64). Install with the setup `.exe` or the `.msi`; the candle sits in the system tray.
- Stay awake while on power, while an external display is connected, or on a weekly schedule such as Weekdays 09:00–18:00. Add them under **Stay awake while → Add → Condition**.
- Pause while the screen is locked, and see the time left next to the candle. Both are in **Settings → General** on Mac.
- Start, stop and check Wick from Shortcuts, Raycast or scripts with `wick://start?minutes=45`, `wick://toggle`, `wick start 16:30` and `wick status`.
- Process names now match what you type, so a `claude` trigger finds Claude Code even though its binary is named after its version.
