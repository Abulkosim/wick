# v0.4.0

2026-10-26 · [Download](https://github.com/Abulkosim/wick/releases/tag/v0.4.0)

- The popover shows how long Wick kept your Mac awake today, with a bar for each of the last 7 days. Time while the Mac sleeps or the screen is locked and paused doesn't count.
- Turn history off or clear it in Settings → History. It stays on this computer for 30 days.
- `wick status` adds `awakeTodayMinutes`.
- Install with Homebrew: `brew install --cask abulkosim/tap/wick`. The cask also links the `wick` command.
