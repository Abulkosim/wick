# v0.8.0

2026-11-10 · [Download](https://github.com/Abulkosim/wick/releases/tag/v0.8.0)

- Wick runs on ARM Linux, such as a Raspberry Pi 4 or 5 with a desktop, ARM laptops and ARM virtual machines: `Wick_0.8.0_aarch64.AppImage`, `Wick_0.8.0_arm64.deb` or `Wick-0.8.0-1.aarch64.rpm`.
- `wick://toggle` and other links work on Windows and Linux while Wick is running. They used to run twice, so a toggle turned the session on and straight off.
- Times are 24-hour everywhere, for example "Awake until 16:30", matching schedules, the tray and notifications.
- When the shortcut, a click on the icon or a link can't start a session, a notification says why, for example "Not started: battery below 20%".
- Setting the clock back no longer lets a Mac sleep before its session ends.
- Updating on Windows keeps a running session going.
- Power, display, schedule and activity triggers that are keeping the computer awake are highlighted like running apps.
- In the add-trigger form, arrow keys move between options, and Escape closes the Until and Custom editor. Screen readers announce changes without reading the countdown every minute.
