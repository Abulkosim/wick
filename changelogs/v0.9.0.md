# v0.9.0

2026-11-18 · [Download](https://github.com/Abulkosim/wick/releases/tag/v0.9.0)

- Wick keeps the computer awake while Claude Code or Codex works and lets it sleep when the agent finishes or waits for you. Connect them in Settings → Agents; Wick backs up the agent's settings file first, and Disconnect removes only its own entries.
- The Agents card in Wick shows each session, for example "Claude Code · wick, Working · 12m". A notification says when the last one ends: "Claude Code finished in wick. Your Mac can sleep again."
- Stop while agents work pauses them until they finish. Settings → Agents → "Keep awake while agents work" turns agent holds off.
- `wick run -- make test` keeps the computer awake while a command runs and exits with its code. `wick hold <name>` and `wick release <name>` hold from any script.
- Windows: install with Scoop, `scoop bucket add wick https://github.com/Abulkosim/wick` then `scoop install wick`. Scoop, AUR and Flatpak installs leave updates to the package manager; Settings → Updates says which.
- Windows: `wick status` no longer shows an old state after Wick changes it.
